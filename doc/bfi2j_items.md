## 教示文・回答尺度（**5件法**, TIPI-Jの7件法と異なる点に注意）
「以下の項目は，あなたにどの程度あてはまりますか。最も近いと思う数字を選んでください。」
- 1: 全くあてはまらない / 2: あてはまらない / 3: どちらともいえない / 4: あてはまる / 5: とてもよくあてはまる

## 採点法
- ドメイン得点 = 該当12項目の得点の和 / 12（逆転項目は処理後）
- ファセット得点 = 該当4項目の得点の和 / 4（逆転項目は処理後）
- 逆転項目（下表の `*` / キー表の `R`）は `6 - x` で反転（5件法なので 6-x）。
